# MRI 장비 현황 대시보드

이 저장소는 대한자기공명기술학회에서 연결하는 **MRI 장비 현황 정적 웹 대시보드**를 GitHub Pages로 공개하기 위한 저장소입니다.

## 이 사이트가 하는 일

- 기본 `장비현황` 탭에서 국내 의료기관의 MRI 장비를 병원명, 시도·시군구, 제조사, 모델명, 테슬라 기준으로 조회·검색·필터링할 수 있습니다.
- `통계분석` 탭에서 전체 장비·의료기관·3.0T 이상 장비·시도 KPI와 제조사, Tesla, 시도, 제조사 × Tesla 통계를 확인할 수 있습니다.
- 활성 탭과 검색 조건은 URL query에 저장되어 공유, 새로고침, 뒤로가기 후에도 유지됩니다.
- 데이터 기준일: **2025-12-31**
- 출처: **건강보험심사평가원(HIRA) 의료장비 상세현황 공개자료**를 정제한 참고용 정보입니다.
- 레코드(요양기관·모델 조합) 수와 실제 등록 장비 대수는 다를 수 있습니다. 한 병원이 같은 모델을 여러 대 보유할 수 있기 때문입니다.

## 이 사이트가 하지 않는 일

- 병원의 전체 도로명 주소 등 상세 주소는 공개하지 않습니다.
- 원자료(raw data) 또는 가공 데이터 파일의 다운로드는 제공하지 않습니다. 조회·필터링 용도로만 제공됩니다.
- 이 저장소에는 정규화 엔진, 모델명 매핑 자산, 원본/가공 데이터가 포함되어 있지 않습니다. 이 사이트의 산출물은 별도의 비공개 저장소에서 생성되어 이 저장소에는 공개 웹 파일만 배포됩니다.

## 데이터 정확성에 대해

이 자료는 2차 가공 정보이며, 최신성 및 정확성에 한계가 있을 수 있습니다. 정확한 최신 현황은 건강보험심사평가원의 공식 자료를 통해 확인하시기 바랍니다.

**데이터 오류 또는 정정 요청은 이 저장소의 [GitHub Issues](../../issues)를 이용해 주시기 바랍니다.** Issue 등록 시 환자정보, 개인정보, 비공개 기관 자료는 절대 포함하지 마시기 바랍니다.

자세한 데이터 출처와 범위는 [DATA_SOURCE.md](DATA_SOURCE.md)를 참고하세요.
